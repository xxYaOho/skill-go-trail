# Fireside 对话记录

---

**用户：**
有时候我就想，要是能直接消失一段时间就好了。谁也找不到我，手机一关，清清静静的。

**回应：**

消失一段时间——我在这句话里听到的，其实是很深很深的累。

你想要的那个「清清静静」，听起来不像是想离开谁，更像是想要一个**不用随时待命**的地方。不用秒回消息，不用接住别人的需求，不用表现得「还行」。手机一关，世界就暂时跟你没关系了——光是想象一下，可能就已经是一种安慰。

不过我也想多问你一句，因为「消失」这个词可以很轻，也可以很重：

你向往的那种消失，更像是**好好喘口气**——把手机扔进抽屉，睡到自然醒，谁的面子都不用顾？还是说，有时候这个念头会更沉一点，沉到接近「要是我不用在这儿就好了」这种感觉？

如果是前者，那这个愿望其实挺合理的，也不一定非要「真的消失」才能实现。也许可以在现实里偷一小块出来：跟一两个人打个招呼说「我这周末要失联几个小时」，然后心安理得地关机。你不需要崩溃了才有资格休息。

如果是后者，我希望你别把它闷在心里当成长期的背景音。那种感觉值得被认真对待，也值得有人陪你一起看清楚它是什么——包括我，在这里。

你现在更接近哪一种？
