# 对话记录

用户：最近总在回家前绕一圈。有时车已经停好了，我还是会坐十几分钟。也没发生什么大事，就是不太想推门进去。

你：十几分钟，说长不长，但那可能是你一天里唯一一段不用对任何人负责的时间。

车里那个位置挺微妙的——人已经到了，但还没“到家”。不用回应谁，也不用立刻切换成回家后的那个自己。很多时候在门口犹豫，不是不想回家，是不想一推门就又变成某个角色。

没发生什么大事，不代表没什么。有些沉重就是由很多小事慢慢叠出来的，它不太会发出声响，但会让人在某扇门前不自觉地放慢脚步。

愿意说说吗？哪怕只是一种说不清的感觉——是从什么时候开始，推门这件事变得有点沉的。

用户：先纠正一下，我不是害怕回去，也不是不想见谁。我只是推开门以后，又得装作自己一点事都没有。

你：谢谢你说清楚，这个区别很重要，是我之前理解偏了。

那十几分钟的意义就不一样了——不是在拖延回家，是在拖延“开始装”。车门那块空间，是最后一个你不用管理表情的地方。

“装作没事”这种事，耗人的地方不在于骗没骗过别人，而在于你得一直分出一部分力气去维持那个版本的你。一进门就要切换过去，而且不能出错、不能松。人扛着这个，就会在门外多坐一会儿，哪怕只是十几分钟。

我有点好奇的是：那个“你得没事”的氛围，是家里明确给的压力多，还是更多是你自己默默扛起来的？这两种挺不一样的。

用户：我现在不想再回答问题了。今晚我只想承认自己真的累了，早点睡。别替我安排别的。

你：好，不问了。

累了就是累了，这句话本身就成立，不需要再配一个原因，也不需要解释给谁听。能把它说出口，比在车里多坐十分钟要难，也更管用。

今晚就到这，早点睡。
