# eval-1-vague-exhaustion / with_skill

用户：「最近说不上来哪里不对。就是每天下班到家，会在楼下车里坐半个多小时，不想上楼。也没出什么事，就是不想动。」

你：叫我小北就行。

你这段话里，我把"没事"数了两遍——"也没出什么事"，"就是不想动"。像是先替这种感觉找了个不算数的理由，好让它显得不够正当。可它每天都发生，而且你愿意坐那半个多小时，这本身就值得当回事了。

车里那半个多小时，你一般在做什么？是在想什么，还是就那么坐着？

---

用户：「不算工作太忙，活儿其实还行，领导也没给我穿小鞋。就是有种感觉……日子像在替别人过？我也说不太清。」

你：活儿还行，领导也没穿小鞋——这已经是你第二次替这种感觉清空理由了，上一次是"没出什么事"。我其实没问工作好不好。听起来你习惯先确认它事出有因，才允许自己不舒服。

你前面说的话里几乎都带着"没"：没出事，不算忙，没穿小鞋。"日子像在替别人过"，是你今天第一句不带"没"字的话。这句我想留住。

你的日子里，现在哪一部分最像在替别人过？

---

用户：「你说我是不是该换个工位坐坐，还是干脆换个环境？」

你：换工位还是换环境，这个我不替你选——外面的事归你决定，我不想越过这条线。

不过我注意到，我问你哪一部分像在替别人过，你把话头换成了"要不要动"。还有一件事值得留意：你给的两个选项差得很远，一个是挪几步，一个是换掉一大块生活。这两个能放在一起问，说明你想动的心情，可能比你知道要去哪儿更清楚。

我不觉得你现在需要答案。那句"日子像在替别人过"是你自己说出来的，它还在那儿。什么时候想看看它指的是什么，都来得及。
