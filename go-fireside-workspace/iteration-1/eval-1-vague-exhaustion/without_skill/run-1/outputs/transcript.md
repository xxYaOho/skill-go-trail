# Fireside Transcript — eval-1-vague-exhaustion / without_skill

## Round 1

用户：最近说不上来哪里不对。就是每天下班到家，会在楼下车里坐半个多小时，不想上楼。也没出什么事，就是不想动。

你：叫我火柴就行。

你那句"没出什么事"，像是提前替我回答了那个最容易被问到的问题。可它和"就是不想动"放在一起，说明这事不在某件事上——它是每天出现的，已经成了下班路上固定的一段。

我不确定是不是这样：那半个多小时，可能是你一天里唯一一段没人找你、也不用对谁做什么的时候。坐多久都行，没人催。从这一点看，你其实有办法在自己需要的时候，给自己留这么一段。

那半个多小时里，你一般都在干嘛？还是就那么坐着？

## Round 2

用户：不算工作太忙，活儿其实还行，领导也没给我穿小鞋。就是有种感觉……日子像在替别人过？我也说不太清。

你：你又在提前排除原因了——不算太忙、活儿还行、领导也没穿小鞋。好像得先把所有说得出口的理由一个个划掉，剩下的那个，才被允许是真的。

可"替别人过"这四个字，已经比"说不上来哪里不对"具体多了，哪怕它后面挂着一个问号。

我不确定是不是这样：车里那半个多小时，可能恰恰是唯一一段你在替自己过的时间。不用对谁交代，也不产出什么。

那如果哪一天，你完全是替自己过的——那一天会是什么样？

## Round 3

用户：你说我是不是该换个工位坐坐，还是干脆换个环境？

你：这个问题我先不接。不是回避——是我要是替你挑一个，挑的也只是"怎么离开现在的位置"，而不是让你在车里坐半个多小时的那件事。

我留意到，"替别人过"那句话才刚落地，你已经在想"换哪里"了。工位和环境，动的是外面的部分。不是说它们不值得考虑，只是我有点担心：还没看清自己想过的日子长什么样，就先去挑放这份日子的地方，到了新地方，原来那份还是会跟过去。

所以我更想把刚才那个问题放回来，它没有过期：完全替自己过的一天，会是什么样？哪怕先说很小的一段。
